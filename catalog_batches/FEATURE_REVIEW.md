# Обогащение признаков

Повторная проверка профилей по источникам выполнена для позиций **1–480** исходного списка `religions.txt`. Следующий диапазон: **481–500**.

Прохождение диапазона не означает, что каждый профиль стал достаточно полным. При нехватке источников он остаётся коротким; ограничения указаны в `notes` соответствующей записи. Решения `alias` и `review` при обогащении не меняются.
